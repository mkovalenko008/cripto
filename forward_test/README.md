# forward_test — прямая проверка идеи «поглощение объёма»

Раз в неделю GitHub Actions (`.github/workflows/forward_test_h1.yml`) запускает `forward_eval.py`: он скачивает публичные
часовые свечи Binance по 203 монетам, пересчитывает результаты гипотезы H1 на данных **после заморозки правил**
(2026-11-05) и обновляет два файла:

- `FORWARD_REPORT.md` — текущие числа и пояснения;
- `history.csv` — по строке на каждый запуск (для графика).

Правила — в `PREREGISTRATION.md` (не менять). Остальные файлы — библиотека расчёта, скопированная из исследования.
Скрипт без состояния: пропущенный запуск ничего не ломает, при следующем он просто пересчитает всё с момента заморозки.
Отключить проверку: в GitHub → Actions → «Прямая проверка H1» → меню «…» → Disable workflow.
